# 港股关键日历 (2026实战版) / HK Stock Market Key Dates 2026

🌟 V3.0 终极修正版 更新说明 (2026.07.26)

本次更新交叉核对了港交所2026年法定休市日历、国际指数公司底层规则、以及港交所2024年交易制度改革，修复了一个致命错误并补全了三个重要缺失事件：

1. 🚨 【致命修正】12月31日「半日市」是错误的！

错误原因： V2.0 误将 12月31日（大除夕）标记为半日市，收盘时间设为中午 12:10。

事实核查： 港交所自 2024年1月起已正式取消圣诞节前夕(12/24)、新年前夕(12/31)及农历新年前夕的半日市安排，这些日期全部恢复为**全日交易**（9:30-12:00, 13:00-16:00, U盘 16:08-16:10）。

V3.0 修正： 12月31日「年终基金排名战」恢复为全日交易，U盘时段为正常的 16:08-16:10。该事件描述已更新为重要提醒。

2. 🆕 【新增事件】2月16日（周一）农历年廿九 — 春节前最后交易日

说明： 2月16日是农历新年假期前的最后交易日。这一天港股全日开市（不再是半日市），但内地A股已开始春节假期，**南向港股通全日暂停**，北水缺席，资金面异常。之后港股休市至2月20日（周五）复市。

3. 🆕 【新增事件】4月2日（周四）复活节+清明节5天长假预警

说明： 2026年4月3日（周五·耶稣受难日）至4月7日（周二·清明节补假）港股连休5天。4月2日是长假前最后一个交易日，且清明节4月5日恰逢周日叠加复活节假期，补假日落在4月7日，这个5天长假极易被忽略。

4. 🆕 【新增事件】10月2日（周五）国庆黄金周翌日 — 南向港股通暂停

说明： 国庆日（10/1）港股休市后，10月2日港股正常开市，但内地仍在国庆黄金周假期中，南向港股通全日关闭，缺少北水支撑。

5. 📝 【用词修正】README 中「除夕」一词更正

原文将12月31日称为「除夕」，但「除夕」特指农历新年的前一天（2026年为2月16日）。12月31日应称「大除夕」或「新年前夜」，已在全文修正。

## 🔔 如何开启提醒 (重要)

**Google 日历用户请特别注意：**
由于 Google 的防骚扰机制，订阅的外部日历默认可能**不会**开启通知。如果你希望在关键日期收到提醒，**必须在导入日历后手动开启**：

1. 打开 **Google 日历网页版**。
2. 在左侧找到已添加的 **"港股实战日历 2026"**。
3. 点击旁边的三个点 `⋮` -> **设置和共享 (Settings and sharing)**。
4. 下滑找到 **"活动通知" (Event notifications)**。
5. 点击 **"添加通知" (Add notification)** -> 设置为 **0分钟** (0 minutes before)。

这样，你就会在每个交易日的 **早上 09:00 (香港时间)** 准时收到提醒，不会错过任何一次行情！
